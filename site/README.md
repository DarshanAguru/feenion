# Feenion Public Website (`site/`)

The static public marketing website and documentation portal for Feenion, designed for zero-config deployment on Vercel or any static hosting provider.

## Structure

- `index.html` — Landing page with interactive code switchers and architecture overview.
- `docs.html` — Exhaustive developer documentation and API reference manual.
- `about.html` — Project mission, engineering commitments, and open-source values.
- `community.html` — Open-source community guidelines, contribution areas, and roadmap.
- `github.html` & `vercel.json` — Vercel routing configuration with clean URLs and `/github` repo redirection.

## Deploying to Vercel

```bash
cd site
vercel
```
