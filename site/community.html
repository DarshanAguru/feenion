Contributing to Feenion

Feenion is an open-source, community-driven project built to give developers complete ownership over AI telemetry and debugging. We welcome contributions from everyone!

🌟 High-Impact Areas We Welcome Contributions

🤖 Framework Integrations

Build plug-and-play auto-instrumentors for LangChain, LlamaIndex, DSPy, CrewAI, and AutoGen.

🌐 Multi-Language SDKs

Help us expand beyond Python to TypeScript/JavaScript (@feenion/sdk), Go, and Rust.

💾 Storage & Exporter Plugins

Implement OpenTelemetry (OTel) exporters, ClickHouse analytic engines, or S3 trace archivers.

📊 UI Widgets & Timeline Visuals

Contribute new Chart.js widgets, DAG flow visualizers, and prompt evaluation comparison views.

How to Get Started

  1. Check Open Issues: Browse our GitHub Issues labeled good first issue or help wanted.
  2. Join the Discussions: Propose new ideas, feature designs, or integrations in GitHub Discussions.
  3. Submit a Pull Request: Follow our CONTRIBUTING.md guide for branch workflows, typing standards, and test verification.

Community Code of Conduct

Feenion is committed to providing a welcoming, inclusive, and harassment-free environment for all contributors. Please review our Code of Conduct.
