Chapter 1

Getting Started & Quickstart

Platform architecture, installation instructions, 60-second quickstart, and demo simulation generator.

Platform Overview

Feenion is a 100% self-hosted, open-source AI debugging and observability engine. It captures complete execution trees, user prompt inputs, completion outputs, token metrics, dynamic model costs, vector retrieval scores, and error stack traces locally on your infrastructure with zero external SaaS dependencies.

Installation & Server Startup

Start the Feenion server in single-container mode (~40MB RAM) using SQLite and an in-memory queue:

git clone https://github.com/feenion/feenion.git
cd feenion
docker compose up -d

Install the official Python SDK client:

pip install feenion

60-Second Quickstart Code 

from feenion import trace, span, configure
from feenion.exporters import HTTPExporter, AsyncExporter

# Configure async non-blocking export transport
configure(exporter=AsyncExporter(HTTPExporter("http://localhost:8000")))

@trace(name="customer_support_pipeline", span_type="agent")
def handle_support_query(user_query: str):
    # Span 1: Vector Search
    with span("kb_retrieval", span_type="retrieval") as s:
        s.input = {"query": user_query}
        docs = ["Doc #1: Feenion runs 100% locally on your machine."]
        s.output = {"documents": docs}

    # Span 2: LLM Completion
    with span("llm_response", span_type="llm") as s:
        s.input = {"prompt": user_query, "context": docs}
        answer = "Feenion is a self-hosted AI observability platform."
        s.output = {"answer": answer}
        s.set_llm_metrics(model="gpt-4o", prompt_tokens=210, completion_tokens=45, cost=0.00098)
        return answer

if __name__ == "__main__":
    print(handle_support_query("What is Feenion?"))

Decorator

feenion.trace(name=None, span_type="general", attributes=None)

Wraps functions or asyncio coroutines into a top-level execution trace. Propagates trace context variables to nested child spans and flushes telemetry upon completion.

ParameterTypeDefaultDescription

Engine

feenion.configure() & Tunable Pricing Registry

import feenion

# Global pricing override ($ per 1 Million tokens)
feenion.configure(
    model_pricing={
        "gpt-4o": (2.50, 10.00),         # $2.50 prompt, $10.00 completion per 1M tokens
        "claude-3-5-sonnet": (3.00, 15.00),
        "custom-llama-3": (0.25, 0.75),
    }
)

# Runtime model rate update
feenion.set_model_pricing("mistral-large", prompt_per_1m=2.00, completion_per_1m=6.00)
Chapter 3

Framework Integrations

Native callback handlers and auto-instrumentation wrappers for LangChain, OpenAI, and Anthropic.

LangChain Integration (FeenionCallbackHandler)

Captures chains, agent loops, tools, retrievers, and LLMs into a single unified trace with automated token and cost tracking:

from feenion.integrations.langchain import FeenionCallbackHandler

handler = FeenionCallbackHandler(trace_name="conversational_retrieval_agent")

# Attach callback to any LangChain agent, chain, or tool
response = agent_executor.invoke(
    {"input": "How do I setup database failover?"},
    config={"callbacks": [handler]},
)

OpenAI & Anthropic SDK Auto-Instrumentation

Feenion provides both instrument_openai(client) / wrap_openai(client) and instrument_anthropic(client) / wrap_anthropic(client). They wrap the client and automatically track completion texts, token counts, and dollar spend: 

# Option A: Functional Wrapper Style
from openai import OpenAI
from feenion.integrations.openai import wrap_openai

client = wrap_openai(OpenAI())
res = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Explain quantum computing in 2 sentences."}],
)

# Option B: In-Place Instrumentation Style
from openai import OpenAI
from feenion.integrations.openai import instrument_openai

client = OpenAI()
instrument_openai(client)

# Anthropic Auto-Wrapper Style
from anthropic import Anthropic
from feenion.integrations.anthropic import wrap_anthropic

claude = wrap_anthropic(Anthropic())
res = claude.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=100,
    messages=[{"role": "user", "content": "Hello Claude!"}],
)
Chapter 4

React Observability Dashboard Manual

Trace Glimpse, Waterfall Flamegraphs, Latency-Scaled D3 Mindmaps, Live Stream Pause, and Model Analytics.

📋 Trace Glimpse & Overview

Instant executive card presenting duration KPIs, prompt query input, final agent output, and token distributions before inspecting deep spans.

⏱️ Waterfall Timeline

Visualizes execution depth with millisecond precision and color-coded span types (LLM, Retrieval, Tool, Error).

🌳 Latency-Scaled Mindmap Tree

D3 graph where connection lengths scale in proportion to span latency, featuring animated flow pulses and interactive zoom controls.

⏸️ Live Stream Freeze

During high-frequency production ingestion, freeze the stream (⏸️ Pause Feed) to inspect traces without viewport jumping.

🤖 Model Intelligence Table

Tracks calls, prompt tokens, completion tokens, volume, cumulative spend ($), avg latency, and cost/1K tokens per model in real-time.

🛡️ Batch Selection & Purge

Select multiple traces with list checkboxes for single-call batch deletion or authenticate with admin:admin to purge the full engine.
