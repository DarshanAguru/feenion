Project Mission & Architecture

About the Feenion Project

Feenion is a brand-new, open-source self-hosted telemetry engine designed specifically for developers building AI agents, RAG search pipelines, and LLM applications.

Why We Built Feenion

Most AI debugging tools require shipping sensitive prompt text, proprietary knowledge base documents, and API secrets to external SaaS vendors. Feenion was built to provide an open-source, self-hosted option that runs locally on your machine or private cloud server with zero data leaks.

Key Engineering Commitments

  • Apache 2.0 License: Completely open-source and free for commercial and personal use.
  • Zero-Overhead Memory Footprint: Uses SQLite in single-container mode (~40MB RAM) so it runs alongside your LLMs without consuming system memory.
  • Non-Blocking Queue Exporter: Decouples trace sending from main Python application threads.
